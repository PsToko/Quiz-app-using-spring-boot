A full-stack quiz web application built with **Java Spring Boot**, **Thymeleaf**, and **Microsoft SQL Server**.

The application allows users to register, log in, answer quiz questions, and view their score, while administrators can manage quiz content through a dedicated admin panel.

---

## Features

### User Features
- User registration
- User login/logout
- Role-based access (`USER`, `ADMIN`)
- Start a quiz with **10 random questions**
- Answer using multiple-choice radio buttons
- Automatic score calculation
- View final quiz result

---

### Admin Features
- Secure admin-only dashboard
- View all quiz questions
- Add new questions
- Edit existing questions
- Delete questions
- Assign questions to categories
- Manage answer options
- Select correct answer
